# c#-tutorial

Учебный проект на C# — консольная игра-бродилка.

## Смысл

Разобраться с базой C# на живом примере, а не на «Hello, world»:
массивы, циклы, условия, ввод с клавиатуры, консоль.

## Суть

- Карта — двумерный массив `char[,]` в [Program.cs](Program.cs).
- Игрок `@` ходит стрелками или WASD, стены `#` не пропускают.
- Собираешь предметы `X` — они попадают в «сумку».
