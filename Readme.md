# c#-tutorial

Учебный проект на C# — консольная игра-бродилка.

## Смысл

Разобраться с базой C# на живой программе, а не на «Hello, world»:
массивы, циклы, условия, методы консоли, ввод с клавиатуры.

## Суть

- Карта — двумерный массив `char[,]` в [Program.cs](Program.cs).
- Игрок `@` ходит стрелками или WASD, стены `#` не пропускают.
- Наступаешь на предмет `X` — он уходит в «сумку», а на карте остаётся `O`.

## Запуск

```
dotnet run
```

Нужен .NET 10 SDK. Управление: стрелки или `W` `A` `S` `D`, выход — `Ctrl+C`.

## Сниппеты

- `for` → `for (int i = 0; i < 0; i++) { }`

Набираешь префикс и жмёшь Tab дважды.
